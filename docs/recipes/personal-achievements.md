# Recipe: personal achievements

**Goal:** besides your designed achievements, each player earns ones that fit *their* style. A dodger gets
*Untouchable*, and a talker gets *Silver Tongue*. Each has a title, an icon, a VFX burst and a condition you can
read.

## Manifest

Designer achievements use the same rule DSL as traits:

```yaml
achievements:
  - id: wordsmith
    title: Wordsmith
    description: Forge five items in five minutes.
    condition: count(forge.created, 5m) >= 5
    glyph: anvil
    rarity: uncommon
  - id: pacifist_run
    title: Not a Scratch on Them
    description: Clear the courtyard without killing anyone.
    condition: count(quest.completed, 1h) >= 1 & count(combat.killed, 1h) == 0
    rarity: epic
modules:
  quests: true
```

**Personal achievements** are generated by the Quests module:

- They come from templates for the built-in traits, plus your designer traits.
- Each goal is set a little above what the player already does, so it is a stretch rather than a gift.
- The AI upgrade gives it a title and description in your lore's tone.

## Game code

```ts
lf.on("achievement.unlocked", (d) => {
  const a = d.args.achievement;                 // {id, title, description, icon {glyph, color, vfx?}, condition, rarity, personal}
  toast(`${a.title}: ${a.description}`, { color: a.icon.color, rarity: a.rarity });
  if (a.icon.vfx) playVfx(buildVfx(a.icon.vfx)); // spark burst
});

// Polling instead (e.g. at the end of a level):
const { unlocked } = (await lf.ask("achievement.check", { recent: shownIds }).instant).result;
```

```gdscript
func _on_directive(kind: String, d: Dictionary) -> void:
    if kind == "achievement.unlocked":
        var a: Dictionary = d.args.achievement
        $AchievementPopup.show_achievement(a.title, a.description, Color(a.icon.get("color", "#ffb547")))
```

## Tips

- **Conditions are evaluated server-side:** on signals, on a short tick and on `achievement.check`. Your game
  only listens.
- **`personal`:** it is `true` for generated achievements, and the dashboard shows it.
- **Moments:** `moment(kind, window)` lets an achievement depend on moments, e.g.
  `moment(near_death_escape, 1h) >= 3`.
